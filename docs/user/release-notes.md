# 版本记录

面向使用者的版本记录，按版本倒序，只列你能感知的变化。发版时把「未发布」段改名为 `## vX.Y.Z`，`tool/upload_release.sh` 从这里提取该段作为应用内更新的更新说明；完整流程见[发布一个版本](../cookbook/publishing-a-release.md)，工程变更的完整记录在 git 历史与 [Agent Notes](../../.agents/notes/README.md)。

## v0.3.2

- 以 MIT 协议开源，GitHub 与 Gitee 同步源码和 Android ARM64 安装包。
- 更新检查与安装包下载通过 Gitee 分发。
- 只提供 Android ARM64 APK，不上架应用商店。

## v0.3.0

### 新增

- AI 服务密钥在「设置 → AI 服务」里自己填写，保存在系统安全存储；源码与安装包不含任何密钥。
- 应用内更新：Android 可以直接下载 APK 并安装，iOS 跳转 App Store（上架后生效）；蓝奏云与 GitHub 作为备选下载入口。

### 变更与优化

- 更新分发走阿里云 OSS，检查更新与下载 APK 在国内网络更稳定。

### 修复

无。

## v0.2.3

### 新增

- Android 支持音量键翻页。
- 阅读界面保持屏幕常亮。
- 应用内检查更新。
- 支持书籍脚注里内嵌的图片。
- 图片查看器支持 SVG 格式。
- 更好地兼容多看平台的排版特性。

### 变更与优化

- 单词解释增加音标、词性、变形与上下文作用。
- 句子分析优先显示整句翻译，语法分析更精简。
- 整体渲染性能与使用体验优化。
- 主页过长的书名改为中间省略。
- 书籍排版与渲染样式优化。
- 书籍详情页的简介显示优化。

### 修复

- 设置界面中组件滑出屏幕后状态丢失。
- 自定义字体相关的若干问题。

## v0.2.2

### 新增

- 支持选择阅读字体。
- 阅读器底部新增状态栏，实时显示当前标题与阅读进度。
- 翻页动画可以开启或关闭。

### 变更与优化

- 设置界面与阅读器下拉菜单里的主题方块样式统一。
- 更好地兼容书籍自带的页面颜色。
- 兼容更多书籍脚注格式。
- 增加部分过渡动画，优化书架列表显示性能。
- 缩放调节滑块两端的「A」图标可以直接点击调节。
- 翻页体验优化。

### 修复

- 书籍导入对话框相关问题。
- 主页底部异常显示的白条。
- 阅读器内链接点击问题。

## v0.2.1

### 新增

- 全局主题系统，支持独立的明暗模式切换。
- 6 款阅读主题预设。
- 设置中心，集中放置配置项与开源协议说明。
- 支持多看平台的脚注格式。

### 变更与优化

- 书架界面视觉重构：多选模式的复选框样式与选中颜色、顶部与底部导航栏及过渡动画。
- 应用内弹窗、下拉抽屉、提示条、按钮边框与阴影在全主题下的视觉统一。
- EPUB 解析提升封面解析成功率与目录相对路径识别准确率。
- 主题面板交互优化。

### 修复

- 部分书籍中字体大小与行高不生效。
- 正文链接点击的精确度。
