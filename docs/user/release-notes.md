# 版本记录

面向使用者的版本记录，按版本倒序，只列你能感知的变化。发版时把「未发布」段改名为 `## vX.Y.Z`，`tool/upload_release.sh` 从这里提取该段作为应用内更新的更新说明；完整流程见[发布一个版本](../cookbook/publishing-a-release.md)，工程变更的完整记录在 git 历史与 [Agent Notes](../../.agents/notes/README.md)。

## v0.4.0

### 阅读与学习

- 更换为 Readium 阅读器，支持 EPUB / TXT 阅读、脚注、图片与目录跳转；优化开书速度、翻页和调整字号后的定位。
- 点词释义以贴近原词的浮卡展示，简义、解释、近义词和构词内容逐步呈现；选中的词有高亮反馈。
- 缩短单词发音等待，获取音频失败时回退到已配置的 TTS 服务。

### 修复

- 修复拖动翻页后停顿松手回弹、关闭图片时误触翻页，以及页面留白无法打开菜单的问题。
- 修复更新下载取消与重试时的状态冲突，改善系统安装器交接。
- 修复存储清理与检查更新期间退出页面引发的异常，并加强损坏备份校验。

### 升级与备份

- 升级保留藏书、分组、学习缓存与旧阅读坐标，无需清除应用数据或重新导入。
- 首次打开旧书时，按原章节与章内比例恢复到近似位置；阅读器排版不同，可能存在页内偏移。之后按新阅读器的完整定位保存进度。
- 支持恢复旧版备份；本版导出的备份需要 v0.4.0 或更新版本恢复。

## v0.3.5

### 修复

- 修复应用内安装失败：点「下载并安装」后系统报「解析软件包时出现问题」。v0.3.0 至 v0.3.4 都有此问题。

### 这次需要手动安装一次

旧版本的应用内安装本身是坏的，它无法把自己修好。请点下面的「GitHub 下载」用浏览器下载安装包，打开文件完成安装；装好本版后，以后的应用内更新就恢复正常了。

## v0.3.4

### 修复

- 修复 Android 16 KB 页大小兼容性：原生库此前只声明 4 KB 对齐，在启用 16 KB 页大小的设备与系统上会被标记为不兼容；本版起所有原生库按 16 KB 对齐。
- 导入或恢复书籍中途失败时，不再留下写了一半的书目，也不会误删操作开始前已经存在的书与封面文件。
- 删除书籍时即使文件清理失败，书架也仍按已删除处理，残留文件在后续存储清理中重试。

### 变更与优化

- 收紧阅读页的时序：翻章与目录跳转在排版完成前不再写入阅读位置，连续切换主题只应用最后一次，退出阅读页后迟到的结果不再改动已保存的进度。
- 恢复备份改为按单本书生效，某一本失败不影响已经恢复好的部分。

## v0.3.3

- 修复点击「检查更新」时因连接提前关闭而失败的问题。
- 修复更新包下载中断，以及检查或下载期间退出页面引发的异常。

旧版本若无法检查更新，请手动下载本版 APK 覆盖安装。
