# Agent Note: 图片查看器在非图片区域短点退出

Status: implemented

## Problem

图片查看器只提供右上角关闭按钮，非图片区域没有关闭动作。用户报告点击关闭按钮或从左边缘返回时，阅读页偶发移动到相邻页；退出图片需要明确消费本次触摸，避免关闭动作与阅读手势混在一起。

## Decision

`ReadiumImageDialog` 用覆盖全屏的点击识别接收非图片区域短点，并消费长按。图片本体单独消费点按，命中范围随 `InteractiveViewer` 的缩放和平移变换，避免把放大后的图片误判为空白。图片查看器不提供关闭按钮，系统返回仍由弹窗路由处理。

关闭发生在短点识别完成后，拖动、取消和图片缩放不触发退出；返回期间已开始的触摸序列不转交阅读页。原生视口、阅读位置与出版物会话保持原有生命周期，见 [Readium 引擎决策](../architecture/2026-09-20-readium-reader-engine.md)。

## Alternatives considered

只移除关闭按钮：非图片区域仍缺少关闭入口，不能满足点空白退出的交互。

整屏点按都关闭：会把图片本体的点按也变成退出，破坏图片与背景的交互区别。

## Consequences

图片充满屏幕、没有可点击留白时仍可使用系统返回。图片网络加载与资源读取路径保持原有行为，不新增文案或设置。

回归测试覆盖 PNG / SVG 外部关闭、图片内点击、缩放和平移后的命中边界，以及拖动、长按、取消和返回期间触摸隔离。组件测试不替代原生阅读器与系统边缘返回手势的设备验收。

## Testing

2026-09-20，在 Android 真机的真实 Readium 视口上打开图片弹窗，用 adb 原生输入交替执行非图片区域点击、系统返回键与左边缘返回手势，共 18 次退出。每次退出后的资源、章内进度、位置和物理页字段均保持不变，测试前后主动翻页均正常。该设备测试直接打开图片弹窗，覆盖关闭手势与原生阅读器的隔离，不覆盖 EPUB 图片点击桥接或 iOS 原生返回手势。
