# 导入与备份

## 支持的格式

| 格式 | 导入后 |
|---|---|
| EPUB 2.0 / 3.0 | 保留原书排版、目录、脚注与图片，并从书里提取封面 |
| TXT | 自动识别编码、按章节切分，可目录跳转，没有封面 |

## 两种导入方式

书架页右下角的 + 按钮展开两项导入入口：

- 导入文件：从系统文件选择器里选一个或多个文件。
- 扫描文件夹：选一个文件夹，递归扫描其中的所有 EPUB / TXT 文件。

导入时显示进度与成功 / 失败数量；单个文件失败不影响其余文件。同一本书（文件内容相同）只加入一次。

## TXT 编码

编码按顺序识别：先看 BOM（UTF-16 / UTF-8），再按 UTF-8 严格解码，都不成立时按 GBK 解码。导入后统一转成 UTF-8 保存，阅读时无需关心原始编码。

把二进制文件改成 .txt 再导入会被判为非文本文件，计入导入失败。

## 封面

EPUB 的封面在导入时提取，独立于书籍文件保存；TXT 没有封面，书架上显示占位图标。

## 备份

点书架左上角的「Synlen」标题进入设置，在「书库」里点「备份书库」：整个书库打包成一个 ZIP 文件，通过系统分享面板保存到你选的位置。备份包含书籍文件、封面、目录结构、分组与阅读进度。

## 恢复

书架页右下角的 + 按钮 → 「从备份恢复」，选择备份来源：

- 备份文件（.zip）：选一个之前导出的 ZIP。
- 备份文件夹：选一份解压后的备份目录。

恢复逐本校验并写回：书架里已有的书以较新的数据为准，分组按名称合并，不会清空现有书架；过程中显示进度与成功 / 失败数量，某本失败不会回滚已经恢复的书。

首次导入的完整流程见 [快速开始](quickstart.md)。
