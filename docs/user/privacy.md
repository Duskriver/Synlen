# 数据与隐私

词镜是离线优先的本地阅读器：书库、进度与学习记录默认只存在你的设备上。学习功能与更新检查可能联网，发送内容见下表。

## 留在设备上的数据

| 数据 | 位置 | 备份导出 |
|---|---|---|
| 书籍文件、封面 | 应用文档目录 | 包含 |
| 书架、分组、阅读进度 | 本地数据库 | 包含 |
| 释义、句子分析、朗读音频缓存 | 本地数据库与缓存目录 | 不包含（可重建） |
| AI 服务密钥 | 系统安全存储（Keychain / Keystore） | 不包含 |

没有账户体系，也没有自建服务端：词镜不上传书库，不做遥测，不含崩溃上报。

## 离开设备的数据

| 触发动作 | 发往 | 发送内容 |
|---|---|---|
| 点词释义 | DeepSeek API | 该单词 + 它所在的句子（作为上下文） |
| 长按句子分析 | DeepSeek API | 句子原文 |
| TTS 朗读 | 阿里云 DashScope | 待朗读文本 + 所选音色 |
| 单词发音音频 | 有道 `dict.youdao.com` | 被点击的单词词形和美音参数（GET 请求），不发送句子上下文 |
| 检查更新与下载安装包 | Gitee | 请求版本清单与 APK，不上传书籍和学习数据 |

DeepSeek 与阿里云请求使用你填写的 AI 服务密钥（BYOK），由对应服务直接校验；有道单词发音无需密钥。不填密钥时，AI 释义、句子分析与 TTS 不可用，其余阅读功能不受影响。

## 备份与清理

- 导出的是**明文 ZIP**，含书籍、封面与阅读进度；分享或存放时请注意保管。密钥与学习缓存不在其中。
- 设置里的「清理缓存」只删除可重建的数据（缓存、孤儿文件），不动书籍与阅读进度。
- 卸载应用会删除设备上的全部词镜数据，不可恢复。
