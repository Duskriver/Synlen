# 用户指南

词镜（Synlen）是一个离线优先的英语学习阅读器：把 EPUB / TXT 书导入设备，阅读时点单词看释义、长按句子看翻译与语法分析，朗读走 TTS。

书籍、阅读进度与学习缓存都保存在设备上；只有点单词释义、句子分析和 TTS 朗读需要联网，并需要你自己填写 AI 服务密钥。

## 支持的格式

| 格式 | 说明 |
|---|---|
| EPUB 2.0 / 3.0 | 保留原书排版、目录、脚注与图片，导入时提取封面 |
| TXT | 自动识别编码并按章节切分，没有封面 |
