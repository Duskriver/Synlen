# 应用内更新

## 检查更新

点书架左上角的「Synlen」标题进入设置，在「项目信息」里点「检查更新」。

App 读取 Gitee 上的 `version.json`，与当前安装的版本比较：已是最新会提示「已是最新版本」，有新版本会弹出更新对话框，你可以在里面看到版本号与更新日志。检查需要联网，读取失败会提示「检查更新失败」。

## Android

点对话框里的「下载并安装」，APK 会下载到应用私有目录，通过校验后打开系统安装器。下载时可点「取消」停止下载并关闭弹窗。系统未允许安装未知来源应用时，会提示你到系统设置里为词镜开启；开启后重新点「下载并安装」，会重新下载。系统安装界面的确认与取消由你决定。

更新是覆盖安装，书架与阅读进度保留在设备上。缺少校验信息或校验失败时不会安装，可使用备用下载入口。

安装成功后，下次启动会自动清理安装包。取消或下载失败留下的不完整文件也会在下次启动时清理；完整但尚未安装的包会保留，重试时重新下载并覆盖。

## 分发范围

仅提供 Android ARM64 安装包，通过公开下载链接分发，不上架应用商店。

## 备选下载入口

服务端的版本信息里带有备选链接时，对话框会多出按钮：

- 蓝奏云下载：有提取密码时先复制密码，再打开蓝奏云页面。
- GitHub 下载：打开清单提供的备用下载链接；当前指向 Gitee APK 附件。

首次安装见 [快速开始](quickstart.md)。
