# 快速开始

从安装到读完第一页。每一步只用到前面已经出现的概念。

## 1. 安装

Android：下载 APK 后直接安装。系统第一次会提示需要允许「安装未知来源应用」，按提示到系统设置里为词镜开启再重试。

iOS：App Store 上架后从 App Store 安装。

## 2. 导入第一本书

打开 App 停在书架页，点右下角的 + 按钮，会展开两项导入入口：

- 导入文件：从系统文件选择器里选一个或多个 EPUB / TXT 文件。
- 扫描文件夹：选一个文件夹，App 递归扫描其中所有 EPUB / TXT 文件。

导入时显示进度，结束后书出现在书架上。EPUB 带封面，TXT 没有封面；同一本书（文件内容相同）只会加入一次。

支持的格式与编码处理见 [导入与备份](import-and-backup.md)。

## 3. 开始阅读

点书架上的书进入阅读界面。

- 点单词：显示音标、释义与用法，可播放发音。释义需要先填 AI 服务密钥，见 [AI 服务密钥](ai-service-keys.md)。
- 长按句子：显示整句翻译与语法分析，可以朗读。
- 点屏幕左右两侧，或左右滑动：翻页。
- 点屏幕中间或底部空白处：显示控制面板，里面有目录、进度与排版设置。
- 长按上/下一页按钮：跳到上/下一章节。

阅读位置自动保存，下次打开回到上次读到的地方；阅读界面底部会显示当前章节标题与阅读进度。

## 4. 整理书架

书架顶部的标签页是分组：全部、未分类，以及你自己建的分组。

- 新建分组并移动书：长按任意一本书进入多选，选中要移动的书，点底部的「移动」，在弹窗里选「创建新分类」并输入名称。
- 改名或删除分组：长按该分组的标签页。
- 排序与显示：点书架右上角的排序按钮，在「显示模式」里选紧凑或宽松，在「排序方式」里选最近添加、最近阅读、标题 A-Z / Z-A、作者 A-Z / Z-A 或阅读进度。
