# 应用内更新

## 检查更新

点书架左上角的「Synlen」标题进入设置，在「项目信息」里点「检查更新」。

App 读取阿里云 OSS 上的 `version.json`，与当前安装的版本比较：已是最新会提示「已是最新版本」，有新版本会弹出更新对话框，你可以在里面看到版本号与更新日志。检查需要联网，读取失败会提示「检查更新失败」。

## Android

点对话框里的「下载并安装」，APK 会下载到应用缓存目录，完成后自动拉起系统安装器。系统未允许安装未知来源应用时，会提示你到系统设置里为词镜开启；开启后重新点「下载并安装」。

更新是覆盖安装，书架与阅读进度保留在设备上。

## iOS

点「前往 App Store」跳到 App Store 里的 App 页面，在 App Store 完成更新（上架后生效）。

## 备选下载入口

服务端的版本信息里带有备选链接时，对话框会多出按钮：

- 蓝奏云下载：有提取密码时先复制密码，再打开蓝奏云页面。
- GitHub 下载：打开对应版本的 GitHub Release 页面。

首次安装见 [快速开始](quickstart.md)。
