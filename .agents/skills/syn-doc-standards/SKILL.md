# Synlen 文档标准

> 先审结构，后改文字。本技能管**放置与结构**；句子级编辑判断交给 `syn-prose-standard`。

## 1. 读权威来源

- `docs/DEVELOPMENT_STANDARDS.md`（§6 领域语言与决策记录、§8 语言约定）、`CONTEXT.md`、`docs/adr/`、`docs/TECH_DEBT.md` #7（已知文档债）。
- 不凭记忆复述规则，回原文核对。

## 2. 结构先行

- **细节层级**：本文档保留全量细节；直接子文档只概述；更深的细节交给后代文档。同级重复展开 = 结构信号。
- **教程 vs 参考**：教程按读者水平排前置概念（过早的概念后移）；参考资料按查找路径组织。混合体拆开。
- **放置**：架构决策 → ADR（三条件：难逆转 / 无上下文会困惑 / 真实权衡）；领域术语 → `CONTEXT.md`；欠账 → `docs/TECH_DEBT.md`；决策护栏与简化提案 → `.agents/notes/`；其余工程文档 → `docs/`。不发明新的顶层位置。
- **移动成本**：移动文档前查配对文件（README 双语对）、入站链接（`rg "旧路径"`）；移动须原子完成（同一 diff 改所有引用）。
- **README 单一中文版**：`README.md` 是唯一 README，全中文（规范 §8.1）；不设英文版，不新建带语言后缀（如 `_zh-CN`）的文档变体。

## 3. 语料审计

- 廉价探针先行：`wc -l` 统计、重复段落搜索、手写"目录 / 索引"页（纯链接列表无增量信息 → 删）。
- 猎取：故事化叙述、变更叙事（→ `syn-trim-cot-leakage`）、对既有规范的转述复制（应链接规范原文而非复制）。
- 排除：`docs/adr/`（已定案记录，不精简）、`docs/TECH_DEBT.md` 条目正文、归档笔记、`CHANGELOG.md`（其本职就是变更叙事）。

## 4. 预算（软规则）

- 新增文档默认 ≤300 行；`README` / `CONTEXT.md` 的增量也受此约束。超标先问：该拆给子文档，还是本就该精简。
- 不能仅凭长度判定文档有缺陷——保留承重规则（一到三行 + 链接），删掉故事、重复与状态说明。

## 5. 验证

- 相对链接逐个核对有效（`rg "\]\(" <file>` 抽查目标存在）。
- 涉及 .dart 注释的改动跑 `dart format` + `flutter analyze`。
- `git diff --check`；PR 正文列出：动了哪些文档、为什么、链接核对结果。
