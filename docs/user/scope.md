# 支持范围

这份说明写清词镜**做什么**与**不做什么**，避免把有意为之的边界当成缺陷。功能细节见[快速开始](guide/quickstart.md)，数据与联网见[隐私](privacy.md)。

## 支持

| 能力 | 范围 |
|---|---|
| 书籍格式 | EPUB 2.0 / 3.0、TXT（自动识别 BOM / UTF-8 / GBK，按章节切分） |
| 导入 | 多选文件、文件夹递归扫描、系统分享进入；按 SHA-256 去重 |
| 书架 | 单层分组、排序、详情编辑、封面、软删除与恢复 |
| 阅读 | 分页、目录、脚注、图片、主题与字体（含导入字体）、阅读进度 |
| 学习 | 点词释义、长按句子翻译与语法分析、TTS 朗读（多音色）、本地缓存 |
| 备份 | 导出 / 恢复 ZIP：书籍、封面、清单、书架与阅读进度 |
| 更新 | 应用内检查更新；分发 Android ARM64 APK，下载后覆盖安装 |
| 平台 | Android、iOS |

## 不支持

| 不支持 | 说明 |
|---|---|
| 加密 EPUB（DRM） | 导入时直接拒绝并提示，不做破解 |
| EPUB 内的音视频 | 读取时忽略，不占内存 |
| 嵌套分组 | 只有单层分组 |
| PDF / MOBI / AZW3 | 只认 EPUB 与 TXT |
| 云同步 / 账户 | 没有账户体系与自建服务端，书库不跨设备同步 |
| 备份加密 | 导出的是明文 ZIP，请自行保管 |
| 桌面 / Web 端 | 仅移动端 |

## 已知边界

- 恢复是逐本进行的：中途失败或取消时，已恢复的书会留在书架上，不保证整体回滚。
- 备份不含学习缓存与 AI 密钥：释义、分析与朗读缓存可重新生成，密钥请重新填写。
- 混淆字体（EPUB 字体混淆）会还原后供阅读；其它形式的加密内容无法打开。
- 已安装的旧版本不会自动降级：更新出错时只能发布更高版本号修复（见[发布故障响应](../cookbook/handling-a-release-incident.md)）。
