# AI 服务密钥

## 为什么需要

藏书、阅读与进度记录都在设备上完成，不需要任何密钥。需要密钥的只有三件事：

| 功能 | 用到的密钥 |
|---|---|
| 点单词看释义与用法 | DeepSeek API Key |
| 长按句子看翻译与语法分析 | DeepSeek API Key |
| 朗读单词或句子 | 阿里云 TTS API Key |

你没填密钥时，这些功能不可用，其余功能不受影响。未配置对应密钥时，DeepSeek 与阿里云 TTS 不会收到任何请求。单词发音会先取免费词典的音频，取不到时才用阿里云 TTS。

## 在哪里填

1. 点书架左上角的「Synlen」标题进入设置。
2. 找到「AI 服务」分组。
3. 点「DeepSeek API Key」或「阿里云 TTS API Key」，在弹窗里粘贴密钥后保存；条目右侧显示「未配置」表示还没填。
4. 想删除已保存的密钥，点开对应条目，用弹窗里的「清除 Key」。

密钥在各自控制台创建：DeepSeek 控制台创建 DeepSeek API Key，阿里云 DashScope 控制台创建 TTS API Key。阿里云 TTS 密钥必须来自北京地域端点，其他地域的 Key 无法使用。

填好后可以点「检查 DeepSeek 连通性」验证密钥与网络，这个检查不消耗 tokens。保存失败会提示「密钥保存失败，请重试」，读取失败时分组里会显示重试按钮。

## 存在哪里

密钥保存在系统安全存储（Android Keystore / iOS Keychain），与书籍数据分开存放。源码与构建产物不含任何密钥，安装包可以公开分发。

## 会发送什么

点单词、长按句子时，对应文本会发送给第三方服务（免费词典、DeepSeek、阿里云 TTS）以获取学习内容；结果缓存在设备上，重复查询直接读缓存。

密钥填好后，点单词与长按句子的用法见 [快速开始](quickstart.md)。
